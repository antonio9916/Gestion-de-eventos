# sistema-gestion-eventos

Sistema de gestión de eventos — Frontend (Angular)

Este repositorio contiene la interfaz de usuario del Sistema de Gestión de Eventos, implementada con Angular, SCSS y componentes reutilizables.

## Desarrollo

Instalar dependencias:

```bash
npm install
```

Iniciar servidor de desarrollo:

```bash
npm run start
```

Abrir: `http://localhost:4200/`

## Estructura básica

- `src/app/` — componentes y vistas principales
- `src/styles.scss` — estilos globales y variables

## Construir

```bash
npm run build
```

Los artefactos se generan en `dist/`.

## Tests

```bash
npm run test
```

## Notas

- Proyecto generado con Angular CLI.
- Todos los datos de muestra son estáticos (mock) y no hay backend incluido.
